# n8n + Twenty CRM на вашому комп'ютері

Навчальне середовище, яке запускається **подвійним кліком**. Ви отримаєте:

* **[n8n](https://n8n.io)** — програму для автоматизацій (з'єднує сервіси між собою без програмування);
* **[Twenty](https://twenty.com)** — CRM-систему (база клієнтів, компаній та угод);
* одну спільну базу даних **PostgreSQL**, у якій обидві програми зберігають свої дані;
* **ngrok** — публічну адресу в інтернеті для вебхуків n8n.

Усе працює лише на вашому комп'ютері і безкоштовно. Знати програмування не потрібно.

## Крок 1. Встановіть Docker Desktop

**Що таке Docker?** Це програма, яка запускає інші програми в окремих «контейнерах» — ніби в закритих коробках,
де вже є все необхідне. Завдяки цьому вам не треба окремо встановлювати й налаштовувати n8n, Twenty та базу
даних — Docker зробить це сам. **Docker Desktop** — це Docker з віконцем для звичайних користувачів.
Для навчання й особистого використання він безкоштовний.

<details open>
<summary><b>Windows</b></summary>

### 1.1. Увімкніть WSL (робиться один раз)

WSL — це вбудований компонент Windows, без якого Docker не працює.

1. Клікніть **правою** кнопкою миші на кнопку **«Пуск»** і виберіть **«Термінал (адміністратор)»**
   (або **«Windows PowerShell (адміністратор)»**). На запит «Дозволити цій програмі вносити зміни?» натисніть **Так**.
2. Скопіюйте цю команду, вставте її у вікно (клік правою кнопкою миші) і натисніть **Enter**:

   ```powershell
   wsl --install --no-distribution
   ```

3. Потім так само виконайте:

   ```powershell
   wsl --update
   ```

4. **Перезавантажте комп'ютер.**

> Якщо з'явилось повідомлення, що WSL уже встановлено, — це нормально, просто переходьте далі.

### 1.2. Встановіть Docker Desktop

1. Відкрийте сторінку <https://www.docker.com/products/docker-desktop/> і натисніть **Download Docker Desktop** →
   **Download for Windows – AMD64**.
   > Варіант **ARM64** потрібен лише для рідкісних ноутбуків з процесором Snapdragon. Перевірити:
   > **Параметри → Система → Про систему → Тип системи**.
2. Запустіть завантажений файл **Docker Desktop Installer.exe**.
3. У вікні налаштувань залиште галочку **Use WSL 2 instead of Hyper-V** і натисніть **OK**.
4. Дочекайтеся кінця встановлення і натисніть **Close** (якщо попросить перезавантажити комп'ютер — перезавантажте).

### 1.3. Перший запуск Docker Desktop

1. Відкрийте **Docker Desktop** через меню **«Пуск»**.
2. Прийміть умови використання — **Accept**.
3. Вхід в акаунт Docker не обов'язковий: натисніть **Skip** / **Continue without signing in**.
   Опитування теж можна пропустити (**Skip**).
4. Зачекайте, поки внизу ліворуч у вікні Docker з'явиться зелений напис **Engine running**.

Готово! Біля годинника на панелі завдань з'явиться іконка кита 🐳.

</details>

<details open>
<summary><b>macOS</b></summary>

### 1.1. Встановіть Docker Desktop

1. Відкрийте сторінку <https://www.docker.com/products/docker-desktop/> і натисніть **Download Docker Desktop**,
   вибравши свій процесор: **Mac with Apple Silicon** (M1–M4) або **Mac with Intel Chip**.
2. Відкрийте завантажений файл **Docker.dmg** і перетягніть іконку **Docker** у папку **Applications** (Програми).

### 1.2. Перший запуск Docker Desktop

1. Відкрийте **Docker** з папки **Програми** (або через Launchpad).
   На запитання «Ви справді хочете відкрити…?» натисніть **Відкрити**.
2. Прийміть умови використання — **Accept**.
3. Якщо Docker запропонує рекомендовані налаштування — погодьтеся і введіть пароль від Mac.
4. Вхід в акаунт Docker не обов'язковий: натисніть **Skip** / **Continue without signing in**.
   Опитування теж можна пропустити (**Skip**).
5. Зачекайте, поки у вікні Docker внизу ліворуч з'явиться зелений напис **Engine running**.

Готово! У верхньому меню з'явиться іконка кита 🐳.

</details>

## Крок 2. Завантажте цей проєкт

1. Угорі цієї сторінки натисніть зелену кнопку **`<> Code`** → **Download ZIP**.
2. Розпакуйте архів:

   **Windows**
   1. Знайдіть файл `n8n_twenty-main.zip` у папці **Завантаження**.
   2. *(Рекомендовано, щоб Windows потім не показувала попереджень)* Клікніть по ньому правою кнопкою →
      **Властивості** → внизу поставте галочку **Розблокувати** (Unblock) → **OK**.
      Якщо такої галочки немає — просто пропустіть цей пункт.
   3. Клікніть правою кнопкою → **Видобути все…** (Extract All) → виберіть, наприклад, папку **Документи** → **Видобути**.

   **macOS**
   1. Двічі клікніть на `n8n_twenty-main.zip` у папці **Завантаження** — поруч з'явиться папка `n8n_twenty-main`.
   2. За бажанням перенесіть цю папку в **Документи**.

> ⚠️ **Не запускайте файли прямо з ZIP-архіву** — спершу обов'язково розпакуйте його.

У розпакованій папці є:

| Папка / файл | Для чого |
|---|---|
| `Windows/` | файли для запуску на Windows |
| `Mac/` | файли для запуску на Mac |
| `examples/` | готові приклади workflow для n8n |
| `docs/` | додаткові інструкції |
| `docker-compose.yml` | «рецепт» для Docker: які програми запускати (змінювати не потрібно) |

## Крок 3. Отримайте дані ngrok

**Навіщо ngrok?** n8n працює на вашому комп'ютері, і з інтернету його «не видно». Але багато сервісів
(Telegram-боти, онлайн-форми, платіжні системи) повідомляють про події, надсилаючи дані на адресу в інтернеті —
це називається **вебхук**. ngrok дає вашому n8n постійну публічну адресу на кшталт
`https://ваша-назва.ngrok-free.app` і пересилає все, що на неї приходить, у ваш n8n.

> Без ngrok теж усе запуститься: n8n і Twenty працюватимуть, просто вебхуки з інтернету не надходитимуть.
> Налаштувати ngrok можна будь-коли пізніше.

1. Зареєструйтеся на <https://dashboard.ngrok.com/signup> (можна через Google-акаунт). Якщо прийде лист — підтвердіть email.
   Якщо ngrok поставить запитання про те, як ви його використовуватимете, — відповідайте як завгодно.
2. Відкрийте <https://dashboard.ngrok.com/get-started/your-authtoken> і скопіюйте **Authtoken** (кнопка **Copy**).
   Збережіть його, наприклад, у нотатках.
3. Відкрийте <https://dashboard.ngrok.com/domains>. Там уже є ваш безкоштовний домен, наприклад
   `cheerful-otter-mighty.ngrok-free.app`. Скопіюйте його й теж збережіть.
   > Якщо список порожній — натисніть **+ New Domain** (або **Create Domain**), і ngrok створить безкоштовний домен.

> 🔒 **Authtoken — це як пароль.** Нікому його не надсилайте і не публікуйте.
>
> Безкоштовного тарифу ngrok (1 ГБ трафіку та 20 000 запитів на місяць) з запасом вистачає для навчання.

## Крок 4. Запустіть систему

Переконайтеся, що **Docker Desktop запущений** (іконка кита 🐳), і:

### Windows

1. Відкрийте розпаковану папку проєкту → папку **`Windows`**.
2. Двічі клікніть на **`start`** (файл `start.bat`).
   > Якщо з'явиться синє вікно «Windows захистила ваш комп'ютер» — натисніть **Докладніше** → **Виконати в будь-якому разі**.

### macOS

**Перший раз** (macOS не дає запускати файли з інтернету подвійним кліком, тож запустимо через Термінал):

1. Відкрийте **Термінал**: натисніть **Cmd + Пробіл**, введіть `Terminal` і натисніть **Enter**.
2. Надрукуйте `bash ` — слово **bash і пробіл** — але **не натискайте Enter**.
3. Відкрийте у Finder папку проєкту → папку **`Mac`** і **перетягніть мишкою** файл **`start.command`** у вікно Терміналу.
4. Натисніть **Enter**.

**Наступні рази** — просто двічі клікніть на **`start.command`** у папці `Mac`.

### Що відбуватиметься

Відкриється чорне вікно, у якому скрипт:

1. перевірить, що Docker працює (і запустить його, якщо треба);
2. **під час першого запуску** створить файл `.env` з вашими персональними паролями — їх генерує сам скрипт;
3. попросить **Authtoken** і **домен** ngrok з Кроку 3 — вставте кожен і натисніть **Enter**
   (вставити: **Ctrl+V** або клік правою кнопкою миші на Windows, **Cmd+V** на Mac).
   Якщо ngrok поки не налаштовуєте — просто натисніть **Enter**;
4. завантажить і запустить програми.
   **Перший запуск триває 5–20 хвилин** (завантажується близько 3 ГБ). Не закривайте вікно!
   Наступні запуски — 1–2 хвилини;
5. перевірить, чи працює тунель ngrok;
6. покаже **«Готово!»** та адреси і відкриє Twenty та n8n у браузері.

Після цього вікно можна закрити (натисніть **Enter**). Програми продовжать працювати у фоні.

## Крок 5. Перший вхід у Twenty та n8n

Акаунти, які ви зараз створите, існують **лише на вашому комп'ютері**. Запишіть паролі!

### Twenty CRM — <http://localhost:3000>

1. Натисніть **Continue with Email** (Продовжити з електронною поштою), введіть свій email і натисніть **Continue**.
2. Придумайте пароль (щонайменше 8 символів) і натисніть **Sign up** (Зареєструватися).
3. **Create your workspace** — введіть назву (**Name**) робочого простору, наприклад «Мій бізнес»,
   і натисніть **Create workspace** (Створити робочий простір).
4. **Create profile** — вкажіть ім'я та прізвище і натисніть **Continue**.
5. Кроки з синхронізацією пошти, запрошенням команди тощо можна пропустити — кнопка **Skip** (Пропустити).

> Мову інтерфейсу можна змінити тут: <http://localhost:3000/settings/experience> → **Language** (Мова).

### n8n — <http://localhost:5678>

1. На сторінці **Set up owner account** вкажіть email, ім'я, прізвище та пароль
   (щонайменше 8 символів, з великою літерою та цифрою) і натисніть **Next**.
2. Анкету **Customize n8n to you** можна заповнити або пропустити (**Get started**).
3. Вікно **Get paid features for free** — безкоштовна ліцензія на додаткові функції (папки, розширений пошук тощо).
   Можна натиснути **Send me a free license key** (ключ прийде на пошту) або **Skip**.

🎉 **Усе готово!** Спробуйте [приклад інтеграції n8n і Twenty](docs/integration-n8n-twenty.md).

## Щоденна робота

| Що зробити | Windows (папка `Windows`) | Mac (папка `Mac`) |
|---|---|---|
| **Запустити** | `start.bat` | `start.command` |
| **Зупинити** (дані зберігаються) | `stop.bat` | `stop.command` |
| **Видалити всі дані й почати з нуля** | `reset.bat` | `reset.command` |
| **Зібрати інформацію для викладача**, якщо щось не працює | `diagnostics.bat` | `diagnostics.command` |

### Адреси

| Що | Адреса |
|---|---|
| Twenty CRM | <http://localhost:3000> |
| n8n | <http://localhost:5678> |
| Публічна адреса n8n для вебхуків з інтернету | `https://<ваш-домен>.ngrok-free.app` |
| Запити, що прийшли через ngrok (для перевірки вебхуків) | <http://localhost:4040> |

Як n8n і Twenty звертаються одне до одного, описано в [прикладі інтеграції](docs/integration-n8n-twenty.md#як-програми-знаходять-одна-одну).

### Корисно знати

* **Після перезавантаження комп'ютера** просто запустіть `start` ще раз — він сам відкриє Docker Desktop, якщо треба.
  (Якщо Docker Desktop стартує разом із комп'ютером, n8n і Twenty теж запустяться самі.)
* **Docker Desktop має бути запущений**, поки ви працюєте з n8n і Twenty. Програми займають близько 3 ГБ пам'яті,
  тож коли не працюєте — запустіть `stop` і закрийте Docker Desktop
  (клік правою кнопкою на іконці кита → **Quit Docker Desktop**).
* **Ваші дані зберігаються всередині Docker**, а не в папці проєкту. Тому видалення папки дані не видаляє —
  для цього є `reset`.
* **Не видаляйте і не змінюйте файл `.env`** у папці проєкту: там ключі до ваших даних. Його копія також
  зберігається у вашій домашній папці (`.n8n-twenty`), тож якщо ви завантажите проєкт заново в іншу папку,
  скрипт `start` підхопить налаштування автоматично.
* **Робоча адреса вебхука в n8n** — **Production URL** — працює, лише коли workflow опублікований (кнопка **Publish**).

## Для викладача

<details>
<summary>Технічні подробиці</summary>

### Склад

| Сервіс | Образ | Примітка |
|---|---|---|
| `postgres` | `postgres:17` | одна інстанція, три бази: `twenty`, `n8n` (користувач `n8n`), `practice` (користувач `student` / пароль `student`) |
| `redis` | `redis:7.4-alpine` | черги Twenty |
| `twenty` | `twentycrm/twenty:v2.49.0` | `http://localhost:3000`, у мережі Docker — `twenty.internal` |
| `twenty-worker` | `twentycrm/twenty:v2.49.0` | фонові задачі (зокрема відправлення вебхуків) |
| `n8n` | `docker.n8n.io/n8nio/n8n:2.44.4` | `http://localhost:5678`, у мережі Docker — `n8n.internal` |
| `n8n-runner` | `n8nio/runners:2.44.4` | зовнішній task runner для вузлів Code (JS і Python) |
| `ngrok` | `ngrok/ngrok:latest` | профіль `tunnel`, вмикається, якщо в `.env` заповнені `NGROK_AUTHTOKEN` і `NGROK_DOMAIN` |

Ключові рішення:

* Порти відкриті лише на `127.0.0.1` — з локальної мережі система недоступна.
* `N8N_EDITOR_BASE_URL=http://localhost:5678` (редактор і OAuth-callback через localhost),
  `N8N_WEBHOOK_URL=https://<домен ngrok>/` (вебхуки через тунель), `N8N_PROXY_HOPS=1`.
* `N8N_SECURE_COOKIE=false` — щоб вхід через `http://localhost` працював і в Safari.
* Twenty за замовчуванням блокує вихідні запити на приватні IP (SSRF-захист). Дозволено лише хост
  `n8n.internal` (`OUTBOUND_HTTP_ALLOWED_INTERNAL_HOSTS`). Аліас із крапкою потрібен, бо форма вебхука в Twenty
  не приймає хост без домену верхнього рівня (`http://n8n:5678` вважається невалідним).
* Скрипт ініціалізації БД вбудований у `docker-compose.yml` (`configs.content`) — жодних bind-mount з диска,
  тож шлях до папки (кирилиця, пробіли, OneDrive) не має значення.
* Ім'я проєкту Compose зафіксоване (`name: n8n-twenty`), тому томи не залежать від назви папки.
* Скрипти зберігають копію `.env` у `~/.n8n-twenty/env-backup` і відновлюють її, якщо проєкт розпаковано
  в нову папку, а томи з даними вже існують.

### Структура скриптів

* `Windows/*.bat` — лише «кнопки», які викликають `scripts/windows/*.ps1` (Windows PowerShell 5.1, файли в UTF-8 з BOM).
* `Mac/*.command` — bash-скрипти (сумісні з bash 3.2), спільні функції — у `scripts/mac/common.sh`.
  Під час запуску вони знімають з папки проєкту атрибут карантину macOS і роблять `.command` виконуваними.
* `.gitattributes` фіксує переноси рядків: `.bat` — CRLF, `.sh`/`.command` — LF. Не змінюйте це, інакше скрипти
  в ZIP-архіві можуть зламатися.

### Ручне керування (для тих, хто знайомий з терміналом)

```bash
docker compose up -d --wait                 # запуск (потрібен заповнений .env)
docker compose ps                           # стан сервісів
docker compose logs -f twenty               # журнали сервісу
docker compose --profile tunnel down        # зупинка
docker compose --profile tunnel down -v     # зупинка з видаленням усіх даних
```

### Оновлення версій

1. Змініть теги образів у `docker-compose.yml` (`twentycrm/twenty`, `n8nio/n8n` і `n8nio/runners` — версії n8n
   та runners мають збігатися).
2. Студенти завантажують новий ZIP, розпаковують у нову папку й запускають `start` — `.env` відновиться з резервної
   копії, Twenty та n8n самі виконають міграції бази.
3. Перед оновленням радимо резервну копію:
   `docker compose exec -T postgres pg_dumpall -U postgres > backup.sql`.

Twenty дозволяє оновлюватися з будь-якої версії v1.23+ одразу до останньої; n8n вимагає PostgreSQL 17+,
Twenty — 15+.
